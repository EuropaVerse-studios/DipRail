# Contributing to DipRail

Thank you for considering contributing to DipRail! We welcome all forms of
contribution: code, documentation, bug reports, and feature requests.

## Code Style

- **GDScript**: Follow the [Godot GDScript style guide](https://docs.godotengine.org/en/stable/tutorials/scripting/gdscript/gdscript_styleguide.html).
- **Comments**: If you add new code, please write comments in **English** so
  everyone can understand. Existing comments are in Italian and will be
  gradually translated.
- **Testing**: Before submitting a pull request, test your changes thoroughly.
  We don't have automated tests yet – manual testing is required.

## Pull Request Process

1. Fork the repository.
2. Create a feature branch (`git checkout -b feature/my-feature`).
3. Commit your changes with clear messages.
4. Push and open a pull request against the `main` branch.
5. Describe what you did and why.

## Reporting Bugs

Open an issue on GitHub with:
- Godot version (4.7 stable)
- Operating System
- Steps to reproduce
- Console output (if any)

## Feature Requests

We have a [Roadmap](#-roadmap) in the README. Feel free to suggest new ideas
via GitHub Issues, tagged as `enhancement`.

Thank you!
